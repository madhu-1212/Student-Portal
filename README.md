
# Student Portal – Threat Modeling and Secure Configuration

## Project Overview

This project focuses on identifying security risks in a fictional Student Management Web Application and recommending appropriate defensive security controls.

The assessment follows the STRIDE threat modeling methodology to identify potential security threats and prioritize them based on likelihood and impact.

## Application Description

The proposed student portal allows students and administrators to access academic information through a web application.

### Main Features
- Student Login
- Administrator Login
- Student Profile Management
- Course Information
- Assignment Submission
- Academic Records

## Project Objectives

- Identify important application assets.
- Understand users and system components.
- Identify security threats using STRIDE.
- Evaluate risks based on likelihood and impact.
- Recommend security hardening measures.

## Deliverables

1. Threat Model Diagram
2. Security Risk Register
3. Prioritized Hardening Checklist

## Methodology

This project uses the STRIDE framework:

- Spoofing
- Tampering
- Repudiation
- Information Disclosure
- Denial of Service
- Elevation of Privilege

## Tools Used

- Visual Studio Code
- Markdown
- Mermaid
- GitHub

## Scope

This is a defensive threat modeling exercise based on a fictional student portal. No real student data or external systems are involved.
